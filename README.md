# AI All-In-One Hub

로컬 AI 도구와 MCP 연결, 프로젝트 분석 및 작업 흐름을 통합하는 Windows 앱입니다.

## 공개 준비 상태

이 저장소는 공개용 소스를 분리하기 위해 생성했습니다. **현재 main에는 소스 코드나 설치 프로그램이 게시되어 있지 않습니다.**

전체 소스에서 개인 설정뿐 아니라 운영 정보와 예제 데이터를 추가 검토하고 있습니다. 검토가 끝난 범위만 새 이력으로 공개할 예정이며, 기존 비공개 저장소와 개인 데이터는 포함하지 않습니다.

설치본은 서명·의존성·Windows 설치 검증을 마치기 전까지 공개하지 않습니다. 다운로드 가능한 릴리스는 아직 없습니다.

공개 라이선스 범위도 검토 중이며, 원본 저작권과 제3자 라이선스를 임의로 변경하지 않습니다.
