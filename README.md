# Hub safety utilities

공개 범위: 비밀값 마스킹, 위험 스크립트 패턴 판별, 합성 데이터 단위시험만 담은 4파일 발췌본입니다. 전체 Hub 앱이나 설치본이 아닙니다. 운영 설정·모델 라우팅·개인 경로·계정·원격 연결·작업 이력은 포함하지 않습니다.

Node.js로 `node scripts/test-script-safety.js`를 실행하면 임시폴더만 사용하는 오프라인 시험을 수행합니다. 문자열 속 명령은 실행하지 않습니다. 패턴 검사는 완전한 보안 검증이나 비밀정보 제거 보장이 아닙니다.

라이선스는 원본 표기와 저작권 고지 검토 후 명시합니다.
