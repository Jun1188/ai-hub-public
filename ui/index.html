    공유 폴더
    
        
    설정·메모리·게임 프로젝트·파이프라인을 Google Drive 내 드라이브를 통해 다른 컴퓨터와 공유합니다. 앱은 항상 로컬 데이터로 동작하고 공유는 백그라운드에서만 이뤄지므로, Drive가 느리거나 끊겨도 앱은 멈추지 않습니다. 한쪽에서 지운 파일이 다른 쪽에서 지워지지는 않습니다.

    원인 프로세스 자원 기록의 진단마다 점유율 순위 · 페이징은 프로세스별 하드 폴트 기준
    
        
    
          
    
        
    
        
        
    
      
    
      
    
        
    렌더링 병목 스레드 이름별 CPU + 프로세스 GPU 엔진 · 관리자 권한 없음 · 프레임 시간은 PresentMon(설치 + Performance Log Users 그룹)
    
        
    
          
          
          
          
        
    
        
    
        
    
        
      
      
      
      
      
        
      프레임 캡처 분석 .rdc 리플레이로 GPU 시간을 측정하거나 RenderDoc XML에서 기록된 API 호출을 확인합니다.
      
        
      
          
          
          
          
        
      
        
      
        
      
        
      
        
      캡처는 직접 만듭니다 — Unreal: RenderDoc 플러그인의 뷰포트 캡처 버튼 또는 콘솔 renderdoc.CaptureFrame, Unity: Game 뷰의 RenderDoc 버튼. Hub는 프로그램을 실행하거나 주입하지 않고 만든 캡처만 읽습니다. 캡처를 만든 RenderDoc 버전이 rdc의 모듈 버전보다 새로우면 열리지 않을 수 있습니다.
      
      
      
      
      
        
      프로세스 상세 PID는 대시보드 프로세스 표에서 고르거나 칸의 제안 목록에서 · 하드웨어 점유 · 바쁜 스레드 · 메모리 맵 파일과 RAM으로 읽혀 들어오는 속도
      
        
      
          
          
          
          
          
        
      
        
      
        
      
        
      
        
      상위 AI는 MCP render_monitor · process_inspect · frame_capture_analyze로 같은 측정을 요청합니다. 사용자 폴더 경로는 %USERPROFILE%로 가려 보여 줍니다.

      게임개발 루프
