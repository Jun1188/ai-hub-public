로컬 모델

설치된 모델 준비

모델 준비는 RAM·VRAM을 사용합니다. 실행 중인 Hub 작업과 메모리 여유를 확인합니다.

기존 모델만 사용하며 다운로드하지 않습니다. 지연 중에는 요청 ID로 상태를 조회합니다. 실패 후에는 실제 모델 상태를 다시 확인하세요.

패널 설정

현재 기능과 권한

패널 설정은 이 화면에만 적용됩니다. 작업자의 수정·테스트 권한과 공급자 설정은 Hub 관리 화면에서 저장합니다. API 키는 모델 입력이나 공유 저장소에 보내지 않고 OS 암호화로 보관합니다.
